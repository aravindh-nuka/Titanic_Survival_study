## Project Name

Titanic Survival Prediction Using Machine Learning

## Project Scope

This project predicts whether a Titanic passenger survived or not based on passenger details such as age, gender, passenger class, fare, and embarked location using Machine Learning techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Streamlit

## Project Workflow

1. Data Collection
2. Exploratory Data Analysis
3. Data Preprocessing
4. Model Training
5. Model Evaluation
6. Prediction
7. Streamlit Interface

## Machine Learning Model

* Random Forest Classifier

## Features Used

* Passenger Class
* Gender
* Age
* Fare
* Embarked
* SibSp
* Parch

## Output

The model predicts whether the passenger is likely to survive or not survive.
